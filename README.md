# AI Learning Portfolio — GE931

เว็บไซต์พอร์ตการเรียนรู้จากสไลด์ GE931 ของ ธีระพัฒน์ เอี่ยมนูน

## โครงสร้าง
- `index.html` — หน้าเว็บไซต์หลัก
- `style.css` — ธีม AI / Responsive / Glassmorphism
- `script.js` — animation และ interaction
- `assets/` — ภาพจากสไลด์และไฟล์ PDF ต้นฉบับ

## เปิดดูในเครื่อง
ดับเบิลคลิก `index.html` ได้เลย หรือเปิดด้วย Live Server

## ฝากบน GitHub Pages
1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลด `index.html`, `style.css`, `script.js` และโฟลเดอร์ `assets`
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch**
5. เลือก branch `main` และ folder `/ (root)`
6. กด Save แล้วรอ GitHub สร้างเว็บไซต์
