02 / PROJECTS

ผลงานทั้ง 6 ด่าน

เลื่อนดูแต่ละขั้นของการทดลอง และเปิดภาพเพื่อดูรายละเอียดจากสไลด์ต้นฉบับ

01IMAGE • AI

สร้างรูปด้วย AI

ทดลองสร้างภาพ “สวัสดีวันจันทร์” และปรับ Prompt ให้ภาพมีรายละเอียดและองค์ประกอบที่ตรงเป้าหมายมากขึ้น

Canva / AI Image
สิ่งที่เรียนรู้การสร้างผลงานที่ดีไม่ได้เกิดขึ้นจากการทำเพียงครั้งเดียว แต่เกิดจากการนำข้อสังเกตและความคิดเห็นมาปรับปรุงทั้งเนื้อหา องค์ประกอบ และความสวยงาม
02MATH • VISUAL

อธิบายความสัมพันธ์ทางคณิตศาสตร์

ใช้ Desmos เพื่อแสดงกราฟและพัฒนาจากสมการเบื้องต้นไปสู่การมองความสัมพันธ์ที่สมเหตุสมผลมากขึ้น

Desmos Calculator
สิ่งที่เรียนรู้ผลลัพธ์แรกทำให้เห็นข้อจำกัด ส่วนผลลัพธ์ใหม่เกิดจากการนำข้อผิดพลาดมาวิเคราะห์และปรับปรุงจนได้คำตอบที่สมเหตุสมผลและสะท้อนสถานการณ์จริงมากขึ้น
03SYSTEM • DIAGRAM

สร้าง Diagram จาก Mermaid Code

เริ่มจากระบบโรงพยาบาลแบบพื้นฐาน แล้วเพิ่มผู้ใช้งาน ระบบฉุกเฉิน นัดหมาย เวชระเบียน ห้องยา การเงิน การแจ้งเตือน และฐานข้อมูล

Mermaid
สิ่งที่เรียนรู้การวิเคราะห์และปรับปรุงจากผลลัพธ์แรกช่วยให้เข้าใจการออกแบบระบบอย่างเป็นขั้นตอน และทำให้ผลงานมีความครบถ้วนมากขึ้น
04LATEX • BOOK

สร้างบทความหรือหนังสือจาก LaTeX

พัฒนางานหนังสือฟุตบอลจากโครงสร้างเบื้องต้น ไปสู่เอกสารที่มีการจัดหน้า สารบัญ และรายละเอียดเป็นระบบมากขึ้น

Overleaf / LaTeX
สิ่งที่เรียนรู้ผลลัพธ์แรก → เรียนรู้จากข้อผิดพลาด → ปรับปรุงรายละเอียด → ได้ผลลัพธ์ใหม่ที่ครบถ้วนและมีประสิทธิภาพมากขึ้น
05SLIDES • AI

สร้างสไลด์สรุปงานด้วย NotebookLM

พัฒนาสไลด์เกี่ยวกับ “ระบบการจำหน่ายผู้ป่วยและเรียกเก็บเงินอัจฉริยะ” พร้อมเพิ่มประเด็น AI Challenges & Ethics เพื่อให้เนื้อหาครบขึ้น

NotebookLM
สิ่งที่เรียนรู้การพัฒนาผลงานไม่ได้จบที่ผลลัพธ์แรก แต่ต้องนำข้อสังเกตมาปรับปรุงเนื้อหาและวิธีนำเสนอ เพื่อให้สื่อสารได้ตรงตามเป้าหมายมากขึ้น
06WEB • GITHUB

เขียนเว็บไซต์เพื่อฝากบน GitHub

นำเว็บไซต์ “Ronaldo Monday Greeting” มาปรับจากต้นแบบให้มีภาพเคลื่อนไหว ปุ่มคำอวยพร เอฟเฟกต์ และรองรับมือถือ

HTML • CSS • JavaScript • GitHub Pages
สิ่งที่เรียนรู้การรับฟังความคิดเห็นและการปรับปรุงอย่างต่อเนื่องช่วยให้ผลงานมีความน่าสนใจ สวยงาม ตอบโจทย์ผู้ใช้งาน และสมบูรณ์ยิ่งขึ้น
